# Статистический анализ сетевых вторжений на UNSW-NB15

Учебное исследование различий между нормальным и вредоносным сетевым трафиком на наборе данных **UNSW-NB15**.

В ноутбуке выполнены описательный анализ, оценка информативности 42 признаков по ROC-AUC, перестановочные тесты, проверка четырёх статистических гипотез, корреляционный отбор признаков и сравнение трёх логистических регрессий на рзных наборах признаков.

## Файлы проекта

- `UNSW_NB15_notebook.ipynb` — код, расчёты и визуализации.
- `unsw_results/` — полученные таблицы (`.csv`) и графики (`.png`).
- `requirements.txt` — библиотеки, необходимые для запуска.

## Исходные данные

Используются официальные обучающая и тестовая выборки UNSW-NB15 (175 341 и 82 332 наблюдения). Их можно скачать на [странице UNSW-NB15](https://research.unsw.edu.au/projects/unsw-nb15-dataset).

Перед запуском положите файлы `UNSW_NB15_training-set.csv` и `UNSW_NB15_testing-set.csv` **рядом с ноутбуком**. Исходные датасеты не включены в репозиторий.

## Как запустить

Откройте терминал в папке репозитория. Рекомендуется создать виртуальное окружение.

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab
```

**Windows (PowerShell):**

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
jupyter lab
```

Откройте `UNSW_NB15_notebook.ipynb` и выполните все ячейки по порядку. При запуске результаты сохраняются в `unsw_results/`.
